# PULUM-PULUM — Умное резюме за 10 минут

Сервис для создания профессиональных резюме через AI-интервью. Превращает "сырой" опыт пользователя в профессиональные формулировки с помощью нейросети.

## 🎯 Концепция: "Интервью с дружелюбным HR"

Вместо скучных форм — пошаговое интервью с наводящими вопросами. Пользователь рассказывает о себе своими словами, а AI "упаковывает" это в профессиональное резюме.

**Пример трансформации:**
- **Пользователь пишет:** "Общался с клиентами, которые тупили, и настраивал им винду"
- **AI превращает в:** "Осуществлял техническую поддержку клиентов, повышая уровень удовлетворенности сервисом (CSAT)"

## 🎨 Темы оформления

Проект поддерживает **две темы**:
- 🌙 **Тёмная** (по умолчанию) — глубокий фиолетовый фон с градиентами
- ☀️ **Светлая** — мягкий лавандовый фон с прозрачными карточками

Переключение темы — кнопка в header (слева от "Возможности"). Выбор сохраняется в `localStorage`.
