# PULUM-PULUM — Умное резюме за минуту

Сервис для генерации профессиональных резюме с помощью искусственного интеллекта (Ollama + qwen3:8b).

## 🎨 Темы оформления

Проект поддерживает **две темы**:
- 🌙 **Тёмная** (по умолчанию) — глубокий фиолетовый фон с градиентами
- ☀️ **Светлая** — мягкий лавандовый фон с прозрачными карточками

Переключение темы — кнопка в правом верхнем углу. Выбор сохраняется в `localStorage`.

## 🏗️ Структура проекта

```
.
├── src/                    # Фронтенд (React + Tailwind)
│   ├── App.tsx            # Главный компонент, роутинг, переключатель темы
│   ├── hooks/
│   │   └── useTheme.ts    # Хук для управления темой
│   ├── pages/
│   │   ├── Landing.tsx    # Лендинг + тарифы
│   │   ├── Survey.tsx     # Многошаговая форма опроса
│   │   ├── Payment.tsx    # Имитация оплаты
│   │   ├── Loading.tsx    # Экран загрузки (AI генерирует)
│   │   └── Preview.tsx    # Предпросмотр резюме (многостраничный)
│   └── index.css          # Стили для обеих тем
│
├── backend/               # Бэкенд (FastAPI + Ollama)
│   ├── main.py           # FastAPI приложение
│   ├── ollama_client.py  # Клиент для Ollama
│   ├── pdf_generator.py  # Генерация PDF
│   └── requirements.txt  # Python зависимости
│
└── index.html            # Точка входа
```

## 🚀 Быстрый старт

### Фронтенд
```bash
npm install
npm run dev
```

### Бэкенд
```bash
cd backend
pip install -r requirements.txt
python main.py
```

### Ollama
```bash
ollama pull qwen3:8b
ollama serve
```

## 🎨 Дизайн

- Две темы: тёмная и светлая
- Glassmorphism эффекты
- Плавные анимации (Framer Motion)
- Адаптивный дизайн
- Многостраничный предпросмотр резюме в формате A4
- Градиенты: фиолетовый `#7c3aed` → циан `#06b6d4`
