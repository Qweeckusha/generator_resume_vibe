### Бэкенд

**backend/main.py**
```
feat: FastAPI приложение с эндпоинтами для генерации резюме

- Создано FastAPI приложение с CORS middleware
- Эндпоинт POST /api/generate-resume — генерация резюме через Ollama
- Эндпоинт POST /api/generate-pdf — генерация PDF из данных резюме
- Эндпоинт GET /health — проверка работоспособности API и Ollama
- Функция build_prompt — формирование промпта для LLM
- Функция parse_model_response — парсинг JSON из ответа модели
- Удалены неиспользуемые импорты (asyncio, Optional)
```

**backend/ollama_client.py**
```
feat: клиент для взаимодействия с Ollama API

- Функция check_ollama — проверка доступности Ollama
- Функция generate_resume — отправка промпта и получение ответа
- Функция list_models — получение списка доступных моделей
- Функция is_model_available — проверка наличия нужной модели
- Конфигурация: модель qwen3:8b, таймаут 120 секунд
- Удалены неиспользуемые импорты (json, asyncio, Optional)
```

```

- Структура: Header, Summary, Experience, Education, Skills
- Удалены неиспользуемые импорты (canvas, ListFlowable, ListItem, pdfmetrics, TTFont)
```
