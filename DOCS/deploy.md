# Инструкция по развёртыванию PULUM-PULUM

Полное руководство по запуску проекта в PyCharm.

---

## Требования

- **Python 3.10+**
- **Node.js 18+** и npm
- **Ollama server** 
- **PyCharm**

---

## Пошаговая инструкция

### Шаг 1: Клонирование репозитория

```bash
git clone https://github.com/Qweeckusha/generator_resume_vibe
```

Или откройте существующую папку проекта в PyCharm: **File → Open → выберите папку проекта**

## Фронтенд (React + Vite)

### Установка зависимостей

Откройте терминал в PyCharm (**Alt+F12** или **View → Tool Windows → Terminal**):

```bash
npm install
```

### Запуск в режиме разработки

```bash
npm run dev
```

Фронтенд будет доступен по адресу: **http://localhost:5173**

### Сборка для продакшена

```bash
npm run build
```

Результат сборки появится в папке `dist/`.

## 🔧 Бэкенд (FastAPI + Ollama) в PyCharm

### Шаг 1: Запуск Ollama

Откройте отдельный терминал и запустите Ollama:

```bash
ollama serve
```

### Шаг 2: Проверка модели qwen3:8b

В другом терминале:

```bash
ollama pull qwen3:8b
ollama list
```

Убедитесь, что `qwen3:8b` есть в списке. Это основная модель

### Шаг 3: Открытие бэкенда в PyCharm

**Вариант A: Открыть backend как отдельный проект**
1. **File → Open**
2. Выберите папку `backend/`
3. В новом окне выберите **This Window** или **New Window**

**Вариант B: Работать с бэкендом в том же проекте**
- Просто откройте файлы из папки `backend/` в текущем проекте

### Шаг 4: Настройка виртуального окружения

1. Перейдите в **File → Settings** (или **Ctrl+Alt+S**)
2. **Project: backend → Python Interpreter**
3. Нажмите **Add Interpreter → Add Local Interpreter**
4. Выберите **Virtualenv Environment**
5. Выберите **New environment**
6. Укажите:
   - **Location**: `<project-root>/backend/venv`
   - **Base interpreter**: Python 3.10+ (выберите из списка)
7. Нажмите **OK**

PyCharm автоматически создаст виртуальное окружение.

### Шаг 5: Установка Python-зависимостей

После создания venv, PyCharm предложит установить зависимости из `requirements.txt`. Если нет:

1. Откройте файл `backend/requirements.txt`
2. Кликните правой кнопкой мыши на содержимое файла
3. Выберите **Install All Requirements**

Или через терминал PyCharm:

```bash
cd backend
pip install -r requirements.txt
```

### Шаг 6: Настройка Run Configuration

1. В правом верхнем углу PyCharm нажмите **Add Configuration...** (или **Run → Edit Configurations**)
2. Нажмите **+** → **Python**
3. Заполните:
   - **Name**: `FastAPI Backend`
   - **Script path**: выберите `main.py` из папки `backend/`
   - **Working directory**: `<project-root>/backend`
   - **Python interpreter**: выберите созданный venv
4. Нажмите **OK**

### Шаг 7: Запуск бэкенда

1. Убедитесь, что в правом верхнем углу выбрана конфигурация **FastAPI Backend**
2. Нажмите зелёную кнопку **Run** (или **Shift+F10**)
3. В консоли должно появиться:
   ```
   INFO:     Uvicorn running on http://0.0.0.0:8000
   ```

Бэкенд будет доступен по адресу: **http://localhost:8000**

### Шаг 8: Проверка работоспособности

Откройте в браузере:
- **API документация**: http://localhost:8000/docs
- **Проверка здоровья**: http://localhost:8000/health

## 🐛 Решение проблем

### Проблема: Ollama не отвечает

**Решение:**
```bash
# Проверьте, запущена ли Ollama
ollama list

# Если нет моделей, установите qwen3:8b
ollama pull qwen3:8b

# Перезапустите Ollama
ollama serve
```

### Проблема: Бэкенд не запускается в PyCharm

**Решение:**
1. Проверьте, что виртуальное окружение создано: **File → Settings → Project → Python Interpreter**
2. Убедитесь, что выбран правильный интерпретатор (venv)
3. Проверьте, что зависимости установлены: `pip list` в терминале PyCharm
4. Проверьте Working directory в Run Configuration (должен быть `backend/`)

### Проблема: Фронтенд не подключается к бэкенду

**Решение:**
1. Проверьте, что бэкенд запущен на порту 8000
2. Проверьте CORS в `backend/main.py` (должен быть `allow_origins=["*"]`)
3. Откройте консоль браузера (F12) и проверьте ошибки
4. Убедитесь, что URL в fetch правильный: `http://localhost:8000/api/generate-resume`

### Проблема: PyCharm не видит npm команды

**Решение:**
1. Убедитесь, что Node.js установлен: `node --version`
2. Добавьте путь к Node.js в PATH системы
3. Перезапустите PyCharm
4. Или используйте встроенный терминал PyCharm (**Alt+F12**)

### Проблема: PDF не генерируется

**Решение:**
```bash
# Переустановите reportlab
pip install --upgrade reportlab

# Проверьте, что все зависимости установлены
pip install -r requirements.txt
```

## 📦 Подготовка к Docker (будущий шаг)

После успешного тестирования можно завернуть проект в Docker. Базовая структура:

### Dockerfile для бэкенда

```dockerfile
FROM python:3.10-slim

WORKDIR /app

COPY backend/requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt

COPY backend/ .

EXPOSE 8000

CMD ["uvicorn", "main:app", "--host", "0.0.0.0", "--port", "8000"]
```

### Dockerfile для фронтенда

```dockerfile
FROM node:18-alpine

WORKDIR /app

COPY package*.json ./
RUN npm install

COPY . .

EXPOSE 5173

CMD ["npm", "run", "dev", "--", "--host"]
```

### docker-compose.yml

```yaml
version: '3.8'

services:
  frontend:
    build:
      context: .
      dockerfile: Dockerfile.frontend
    ports:
      - "5173:5173"
    depends_on:
      - backend

  backend:
    build:
      context: .
      dockerfile: Dockerfile.backend
    ports:
      - "8000:8000"
    environment:
      - OLLAMA_BASE_URL=http://host.docker.internal:11434
```

**Примечание**: Ollama должна быть запущена на хост-машине, а не в контейнере (или использовать отдельный контейнер для Ollama).
